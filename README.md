> First CSS styling for the BiteBox website – CSS reset, logo sizing, and navigation hover effects.

---

### 📌 Project Overview
This lab introduces **CSS** to the BiteBox multi-page website.  
A basic stylesheet is linked to control page defaults, logo size, and navigation link appearance with a hover effect.

---

### ✨ What Was Added

**CSS (`css/style.css`)**
- CSS Reset (`margin`, `padding`, `box-sizing`)
- Global font family (Arial, Helvetica, sans-serif)
- Logo sizing (`.logo`)
- Navigation link styling (`nav a`)
- Hover effect on navigation links (color + underline)

**HTML**
- Linked external CSS file in `index.html`
- Multi-page structure retained (Home, Menu, About, Contact, Cart)

---

### 📄 Pages Included

| Page    | File           | Description                          |

| About   | `about.html`   | About page                           |
| Contact | `contact.html` | Contact page                         |

---

### 🛠️ Skills Demonstrated
- Linking external CSS (`<link rel="stylesheet">`)
- CSS Reset
- Element and class selectors
- Pseudo-class (`:hover`)
- Basic typography and spacing
- Navigation styling

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Hover over navigation links to see the CSS effect
